## 验证环境与范围

- 本机 macOS arm64，Electron 开发应用已启动，实际检查了新导航与默认三栏。
- 浏览器使用真实 Vue App 和组件；仅 Electron 文件、配置和 Agent API 由 `doc_local/` 本地夹具代替，测试内容均为合成数据。
- 深浅主题、1200×800 / 800×600、18px 编辑字号均已烟测；浏览器未捕获 error/warn。
- 文件树以 40 个文件和超长文件名验证，水平与垂直滚动值均发生变化；打开 A→修改→打开 B→返回 A 保留草稿。
- 原生文件选择对话框的自动化访问超时，因此未声称完成原生文件对话框、导出落盘或真实付费 Agent 调用的端到端验证；这些 IPC/业务实现保持原样，相关逻辑由既有测试覆盖。
