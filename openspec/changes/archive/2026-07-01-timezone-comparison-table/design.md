## Context

时间工具已有实时时钟、时间戳转换和 Cron 解释。多时区对照表应复用现有 `liveTime` 定时刷新，不新增 IPC 或持久化。时区格式化可使用浏览器内置 `Intl.DateTimeFormat`。

## Goals / Non-Goals

**Goals:**

- 预置常用城市/时区，并允许添加、移除。
- 实时显示每个时区的当前日期、时间和相对本地日期差异。
- 保持纯前端离线实现。

**Non-Goals:**

- 不做会议时间选择、办公时间重叠、DST 解释或持久化自定义城市。
- 不调用外部时区 API。

## Decisions

1. 使用 `Intl.DateTimeFormat` 格式化指定 IANA 时区。
   - 原因：浏览器内置、离线、能处理 DST。

2. 预置固定时区列表，UI 通过 select 添加。
   - 原因：满足常用对照场景，避免自由输入无效 IANA 名称造成复杂校验。

3. 日期差异按本地日期与目标时区日期比较。
   - 原因：直接表达今天、明天、昨天等用户最关心的信息。

## Risks / Trade-offs

- 系统 Intl 数据异常会导致格式化失败 → helper 返回明确错误。
- 自定义城市不持久化 → 符合本次轻量范围，后续可独立扩展。
