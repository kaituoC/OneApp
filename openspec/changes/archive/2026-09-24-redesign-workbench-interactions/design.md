## Context

基线为 main d261107，1.29.0，已有 295 项测试通过。所有工具已实现；原型仅作布局与交互依据，不能替代现有实现。

## Goals / Non-Goals

**Goals:** 复用组件和 helper，集中导航元数据，完善会话状态，复刻审定原型的层级与关键交互。

**Non-Goals:** 不删除任何工具，不修改主进程 Agent 编排、IPC、持久化、安全边界，不引入新依赖或修改 CI。

## Decisions

- 保留现有 tab key 与数字快捷键映射，重新分组；旧分组记忆校验所属关系，失效时回退首工具。搜索、顶部入口、子工具和快捷键共用选择函数。
- App 统一工具页标题、搜索与主题入口；具体工具沿用原有输入输出、算法、错误处理和配置组件，避免重写业务逻辑。
- 编辑器 flex 三栏、子栏 min-width 约束与独立 overflow；树内容使用 max-content，外层有界，不采用截断节点文字的旧策略。
- 数据工具保存每模式状态，生成器缓存每工具结果；文本共享输入并缓存操作结果。发送目标注册 getter，让发送前能在原页面弹出覆盖保护。
- 文件草稿只缓存已修改文件，恢复时不写盘；已保存且未改动文件再次打开仍读取磁盘。
- 时间方向切换使用原有 ref 与 handler，所有格式/单位保留；研讨只重排 template 与 CSS。
- doc_local 忽略规则与用途同步写入 AGENTS/CLAUDE，保存独立可打开的原型 HTML。

## Risks / Trade-offs

- 分类重排导致旧导航记忆错位 → 校验分组归属、保留原数字快捷键并回归测试。
- 子工具切换或异步二维码结果覆盖其他工具 → 使用会话快照与请求归属校验。
- 800×600 三栏较紧 → 目录最小宽度、编辑/预览各自滚动、保留显示开关。
- 原型简化功能被误视为删除 → 逐模块功能对照与基线测试，业务 helper 与主进程不做替换。

## Migration Plan

完成规格、实现、回归及 UI 烟测，执行 high 级代码复查、归档与严格校验，更新文档与 1.30.0 CHANGELOG；最终测试构建后提交推送、PR 合并、Release。回退可通过新提交还原本次改动，不更改历史。
