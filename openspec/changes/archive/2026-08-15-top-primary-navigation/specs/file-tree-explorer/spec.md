## ADDED Requirements

### Requirement: 文件树层级可扫描

统一编辑器的文件树 SHALL 通过一致的缩进、展开状态和低干扰结构线表达父子目录关系，而不改变既有懒加载或文件打开行为。

#### Scenario: 嵌套目录层级可见
- **WHEN** 用户展开包含子目录的文件夹
- **THEN** 每层子节点使用稳定的递进缩进，并显示从父节点延伸的结构线或等价视觉关系

#### Scenario: 文件夹状态可区分
- **WHEN** 用户查看折叠或展开的文件夹节点
- **THEN** 展开控件和文件夹图标共同表达当前状态，当前文件或键盘焦点也具有清晰但不过度突兀的状态
