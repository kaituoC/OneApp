# 弹窗盘点和验证

## 盘点结论

| 入口 | 原问题 | 处理 |
| --- | --- | --- |
| 发现新版本（手动/启动） | Markdown 被压成单段并截断，原生弹窗窄且无法显示完整长说明 | 完整说明字段 + 应用内更新详情，标题/列表/代码排版，正文滚动，安装信息与底部操作分区 |
| Markdown 语法介绍 | 普通 div 遮罩无 modal 焦点约束/Esc；后台快捷键仍可能执行 | 接入原生 dialog 容器，焦点循环、关闭恢复和后台快捷键隔离 |
| 发送到已有内容 | 仅显示前 400 字且未提示截断；长串缺少强制换行 | 完整纯文本、自动换行、正文滚动、固定取消/追加/替换 |
| 工具搜索 | 可覆盖其他 modal；尺寸/关闭与其他弹窗不一致 | 共享容器，搜索框/底部说明固定，不叠加 modal |
| 已是最新版本 / 检查失败 | 短文本，无相同长内容排版问题 | 保留系统消息框与 OneApp 图标 |
| 研讨费用确认 | 固定短说明，无相同问题 | 保留原确认和计费提示语义 |
| 文件/目录/保存对话框 | 操作系统文件选择器，不展示 Release 长说明 | 保留原实现 |

## 验证

- 使用 Codex 浏览器测试真实 App 和组件，Electron API 用本地合成夹具替代；未触发下载、安装或真实 Agent 调用。
- 深浅主题、800×600 / 1200×800：更新 Markdown、底部按钮、长正文滚动；无框架错误页或控制台 error/warn。
- 语法帮助：Tab 从末尾返回关闭按钮；Esc 关闭，焦点回到「更多」。更新详情关闭后焦点回到「检查更新」。
- 自动更新在语法帮助期间到达：仅有一个 modal；帮助卸载后等待更新能继续显示。已修复原生 close 事件迟到造成的请求丢失，并补测试。
- 发送确认：1410 字完整内容，正文高度 879px 在 434px 可视区域滚动，底部按钮仍在 600px 窗口内；取消不覆盖输入。
- 搜索 JSON/二维码并 Enter 跳转正常；其他 modal 内 Cmd+K 不叠加搜索。
- high 复查覆盖说明消毒、HTTPS 链接、完整内容、监听清理、关闭竞态与发送行为；未发现剩余高优先级问题。
- `npm test`：30 个文件、312 项通过；`npm run build`：通过（既有 marked 混合导入提示）。最终门禁在归档与版本更新后再次运行。
